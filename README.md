# mirandas-progress-tracker ✔️ (v1)
A clean daily/weekly/monthly progress tracker built with HTML and CSS. JavaScript enhancements coming in v2.

## Built With
- HTML5
- CSS3 (Flexbox for layout + custom styled checkboxes)

## Purpose
This project is part of my web development learning journey and focuses on clean UI design, semantic HTML structure, and interactive styling using CSS.

## Features
- Daily check-in buttons for hydration, movement, and deep work
- Weekly reflection and focus planning
- Monthly goals and adjustment tracking
- Collapsible sections using `<details>` for clean organization

## Coming in v2
- JavaScript totals (auto-calculate daily and weekly progress)
- Task and nourishment tracking
- Local storage to save progress
